# Contributing

Thanks for helping improve Skillxtube Learning Engine.

1. Open an issue for large changes so the approach can be discussed first.
2. Keep the core library provider-agnostic and free of network calls.
3. Add or update tests for behavior changes.
4. Run `npm test` and `npm run build` before opening a pull request.
5. Never commit API keys, private learning material or personal data.

By submitting a contribution, you agree that it may be distributed under the project's MIT license.
